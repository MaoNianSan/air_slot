# Validation Boundary

Validation checks contracts and bounded behavior without becoming a second scientific pipeline.
The foundation CLI supports fixture-only contract, adapter, and PRE checks. The bounded M1 smoke
uses a small real-data cohort, verifies finite probabilities, deterministic scenario lineage, and
raw read-only behavior, and remains `paper_result=false`.

Full-year validation, Final Test, formal Exp1-Exp4, LLM audit, and paper promotion are outside the
current checkpoint. Raw data, caches, outputs, model weights, and logs remain local and ignored.
