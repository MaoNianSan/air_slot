# Foundation Contracts

These contracts define the first Air Slot implementation milestone. They are normative for task
generation but do not themselves authorize source implementation.

- [adapter-protocol.md](adapter-protocol.md): dataset-neutral adapter surface and independent instances.
- [pre-foundation.md](pre-foundation.md): PRE skeleton inputs, outputs, and invariants.
- [registry-schemas.md](registry-schemas.md): machine-readable registry requirements.
- [downstream-boundaries.md](downstream-boundaries.md): M1-M4 and experiment placeholders only.
- [validation-cli.md](validation-cli.md): offline validation interface and artifact status.

If a contract conflicts with the authoritative documents, the priority order in the constitution
applies and the conflict must be recorded before implementation.
