# Replay Infrastructure Reuse

Status: `IMPLEMENTATION_COMPLETE_NO_EXP2_SCIENTIFIC_RUN`

## Reused Generic Infrastructure

`exp/common/replay/` provides a dataset-agnostic replay boundary with three
concerns only:

- `episode_replay.py` validates frozen episode identity, legal input
  availability at the information cutoff, explicit episode selection, and an
  optional expected split. It constructs M1 scenario requests by copying the
  selected episode ID, decision-node ID, timestamps, cutoff, and lineage.
- `lineage_validation.py` verifies that the constructed M1 request and the M2
  consequence input preserve the selected PRE identity, cutoff, scenario IDs,
  and scenario lineage exactly.
- The layer receives an already frozen registry. It neither scans raw data nor
  selects a cohort, and it does not create scientific artifacts.

The implementation reuses the generic constraints previously expressed by
PRE factual replay legality, PRE episode containment, M1 temporal split
containment, and the shared M1-to-M2 scenario-lineage contract. The new layer
is an Exp-owned adapter boundary; those source modules remain unchanged.

## Exp2 Data2 Binding

`exp.exp2.execution.data2_selector` now supplies the Data2 identity constants
and public error-code namespace, then delegates episode selection, scenario
construction, and PRE-to-M1-to-M2 lineage checking to `exp.common.replay`.
Data2 remains the primary dataset: no Data1 fallback, row discovery, raw data
read, or source-overlay behavior was added. The Data2 adapter requires the
caller to provide the frozen split and rejects an episode outside it.

Artifact validation remains in the established Exp2 execution gate. The
generic `exp.common.artifacts` utilities enforce frozen-artifact namespace and
immutability requirements, while `exp.exp2.artifacts.validator.Exp2ExecutionGate`
continues to validate the exact M1-M4 bundles required for Exp2. Those checks
are not replay-specific and were not duplicated in this package.

Exp2 remains preparation-only. The current scientific manifest still requires
a frozen Data2 version, split, episode registry and IDs, plus exact M1 through
M4 artifacts. No Exp2 scientific experiment or paper result was generated by
this change.

## Discarded Legacy Assumptions

No Exp1 warning behavior was migrated. In particular, the reuse layer does not
include warning probabilities, operating-point selection, thresholds,
false-positive rates, recall, sustained-warning classification, lead-time
metrics, or warning artifact evaluation. Those remain Exp1-specific logic.
