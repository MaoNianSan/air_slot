No real monetary-system mapping is scientifically frozen. The machine-readable design is `registries/m4_v2_monetary_mapping_design.json`; all seven production rows therefore abstain rather than invent a price.

For any future system—RMB accounting, a regulatory loss basis, or another declared system—only `f_k^m` and its registry lineage may change. The input `C_k^{a,CU}`, action ID, scenario IDs/weights, component support, M2 lineage, and M3 response provenance must remain identical.

`TEST_ONLY` mappings exercise the interface but are neither entries in this production matrix nor real monetary evidence. A different test scale producing a different `L` demonstrates separation, not calibration.
