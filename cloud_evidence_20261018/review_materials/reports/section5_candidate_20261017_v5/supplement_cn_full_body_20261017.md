# Supplementary Material（中文共识稿）

## 说明

本补充材料对应正文 Section 5，说明年度样本、信息表示、后果尺度、决策计算与推断单位，并列出逐年结果。本文以 2017—2022 六个年度窗口分别报告结果；跨年均值为六个年度点估计的等权平均，年度范围为最小值至最大值，不是置信区间。除明确说明外，文中不把模拟决策值解释为实际航司节省、实际运行改善或因果效应。

## S1. 记号、分析总体与时间设计

基本分析对象是由飞机尾号连接的前后序航班链在某个预设阶段形成的一个决策案例。年度记为 \(y\)，运行阶段记为 \(g\)，情景记为 \(s\)，决策时点记为 \(t\)。情景权重表示条件状态分布中的概率质量，不是独立样本；同一航班链上的 PRE、TURN 观察及滚动时点也不作为独立统计样本。

本文区分以下总体：

- \(\mathcal C_{1,y}\)：年度 \(y\) 中满足 Stage-II 全部共同支持条件的 PRE/TURN 案例总体，与筛查优先级无关。
- \(\mathcal C^{HJ}_{y}\)：年度 HJ 参考筛查名单与有效 Stage-II 支持的交集，是表示比较和恢复目标比较的年度配对参考队列。
- \(\mathcal C_0\)：旧版 2019 固定样本，只用于历史溯源，不与六年结果合并。
- \(\mathcal C_3\)：同一航班链内重复出现的可用滚动决策时点；本轮六年结果没有估计该总体上的轨迹效应。

因此，\(\mathcal C_{1,y}\) 的全体 Stage-II 有效样本量、\(\mathcal C^{HJ}_{y}\) 的 HJ 配对队列规模，以及 Stage-I 的筛查候选数是不同分母。表 S1 并列给出这些数量和年度恢复参数。

### 数据来源与年度划分

BTS On-Time Performance 提供航班计划、运行节点、滑行时间及飞机连续性；NOAA Integrated Surface Database 提供机场天气观测；BTS DB1B 与 T-100 提供历史旅客市场、连接暴露和航线/运行规模参考。DB1B、T-100 所构造的暴露是历史代理量，不是同一航班的实际旅客清单。决策节点的运行状态信息与训练期冻结的暴露参考分别处理；实际结果用于验证，不作为更早决策时点的输入。

每个年度独立采用相同的时间角色：1—6 月用于模型估计和历史参考形成，7 月用于概率校准，8—9 月用于开发检查和冻结，10—12 月作为年度留出评估窗口。该设计评估的是各年度内独立形成的结果，不构成仅用 2019 年训练后直接迁移至其他年份的转移实验。

五分钟滚动回放用于产生决策节点，再按预设规则映射至 PRE、TURN 等阶段。先按阶段规则确定 canonical node，再检查概率预测支持；不能改为只挑选概率接口有效的节点。有效样本须满足时间质量、所需字段和概率共同支持要求。筛查结果以年度和阶段为单元；Stage-II 表示比较只在各自定义的共同支持队列上进行。

## S2. 条件运行状态与信息表示

令 \(T^{IB}\) 表示前序航班入位/停靠相关状态，\(D^{OB}\) 表示后序航班推出延误，\(D^{TX}\) 表示额外滑行延误。三者均未观测时，条件状态按飞机运行顺序分解为

\[
\begin{aligned}
p(T^{IB},D^{OB},D^{TX}\mid\mathcal E_{\leq t})
={}&p(T^{IB}\mid\mathcal E_{\leq t})\\
&\cdot p(D^{OB}\mid T^{IB},\mathcal E_{\leq t})\\
&\cdot p(D^{TX}\mid T^{IB},D^{OB},\mathcal E_{\leq t}).
\end{aligned}
\]

本文将 History+Joint、History+Marginal、History+Point 和 Current+Joint 分别简称为 HJ、HM、HP 和 CJ。

在决策时点已经实现的节点作为观测固定，不重新抽样。HJ 表示保留联合情景结构及其概率权重；HP 以加权联合情景中的代表点表示状态分布；HM 则使用 HJ 三个未决原始状态的加权边际分布构造精确离散乘积耦合。HM 的目标是保留每个原始状态的一维加权边际、改变其跨状态联合耦合。它是数学上的依赖结构对照，不代表真实运行状态彼此独立，也不作为可部署的联合状态预测。

逐年审计对每个纳入的候选节点比较 Joint 与 HM 在各原始坐标取值上的概率质量。审计结果在六年支持节点上均通过精确加权边际检查，且完全支持条件的概率质量为 1。HM 与 HJ 的后果分量比较显示，Flight 与 Resource 分量在六年均数值一致（最大绝对差小于 \(10^{-13}\) CU）；Passenger 分量在 39%—66% 的节点上有差异，来源于阈值事件后果。该结果说明在当前后果体系中，表示耦合差异通过阈值型后果影响决策；不据此宣称真实运行状态存在独立性或物理可行性。

CJ 与 HJ 还涉及不同时间输入配置。若未同时控制模型容量等实现差异，CJ–HJ 只能作为实现配置对比，不能单独识别历史信息的因果贡献。本稿不将这一对比用于“模型优于模型”的主张。

## S3. 后果指标、管理目标与局部恢复计算

### 后果分量及其解释

令 \(D^{TO}=D^{OB}+D^{TX}\)，\(N^{pax}\) 为历史旅客暴露，\(s^{conn}\) 为连接敏感旅客占比，\(E^{down}\) 为下游暴露代理。后果向量由三个 Flight、三个 Passenger 和一个 Resource 分量组成。

### 表 S2. 七个原始后果分量

| 领域 | 分量 | 原始量 | 含义与限制 |
|---|---|---|---|
| Flight | \(F_{\mathrm{continuity}}\) | \(\max\{0,\ T^{IB}_{signed}+T_{\mathrm{turn,ref}}-SOBT_{relative}\}\) | 训练期冻结周转参考下的连续性/周转压力；采用当前运行的时间坐标合同 |
| Flight | \(F_{\mathrm{execution}}\) | \(D^{OB}\) | 推出延误 |
| Flight | \(F_{\mathrm{propagation}}\) | \(D^{TO}E^{down}\) | 下游暴露加权的延误传播代理 |
| Passenger | \(P_{\mathrm{time}}\) | \(N^{pax}D^{TO}\) | 旅客延误暴露 |
| Passenger | \(P_{\mathrm{itinerary}}\) | \(N^{pax}s^{conn}\mathbf 1\{D^{TO}>45\}\) | 45 分钟阈值下的连接风险代理 |
| Passenger | \(P_{\mathrm{service}}\) | \(N^{pax}\mathbf 1\{D^{TO}\ge180\}\) | 180 分钟阈值下的服务暴露代理 |
| Resource | \(R_{\mathrm{operating}}\) | \(D^{TX}\) | 额外滑行时间代理 |

注：\(T_{\mathrm{turn,ref}}\) 是连续性后果使用的训练期冻结周转参考；Stage-II 可行性计算中的年度下界 \(T_{\mathrm{turn,lb}}\) 是另一参数，不应混为同一个量。旅客和下游变量均为历史暴露代理，不直接等同于实际误接、补偿支出或可实现的航司成本。

连续正值分量 \(k\) 以对应年度训练期的正值中位数 \(\xi_k=\mathrm{Median}_{Train}(q_k\mid q_k>0)\) 标准化，\(Z_k=q_k/\xi_k\)。阈值事件分量按一个原生事件单位标准化。Flight 与 Passenger 领域内各自三个分量等权平均；Resource 领域只有一个分量。CU 为无量纲、按规范设定权重的后果单位，不是货币单位，也不是经显示偏好估计的福利尺度。

### 预设目标权重

| 目标 | Flight 权重 | Passenger 权重 | Resource 权重 |
|---|---:|---:|---:|
| Balanced | \(1/3\) | \(1/3\) | \(1/3\) |
| Flight emphasis | 0.50 | 0.25 | 0.25 |
| Passenger emphasis | 0.25 | 0.50 | 0.25 |
| Resource emphasis | 0.25 | 0.25 | 0.50 |

各领域内部的组件先按上文规则汇总，再按目标权重形成总体后果准则 \(\Phi^C\)。因此，领域等权不意味着七个原始组件完全等权。

### Stage-I 筛查与 Stage-II 局部恢复

对于年度 \(y\)、阶段 \(g\)，筛查容量为 \(K_{y,g}(q)=\lceil qN_{y,g}\rceil\)，在相同候选总体上按固定规则选择优先级最高的案例。名义容量为 \(q_0=0.10\)，容量敏感性采用 \(q=0.05,0.20,0.30\)。替换率衡量替代排序相对参考名单的位置变化；\(L^{att}\) 衡量替代名单保留的参考后果损失，二者回答不同问题。

恢复目标 \(u\) 以五分钟为步长，从 0 到当年 \(U_{\max}\) 取值。情景 \(s\) 下可行的推出时间下界、可用余量和实际应用恢复量写为

\[
LB^{OB}_s=\max\{SOBT^+,T^{IB}_s+T_{\mathrm{turn,lb}}\},\quad
H_s=[AOBT_s(0)-LB^{OB}_s]_+,\quad
r_s(u)=\min\{u,H_s\}.
\]

在目标权重 \(\boldsymbol\omega\) 下，优化

\[
J_{\boldsymbol\omega}(u)
=\sum_s w_s\Phi^C_{\boldsymbol\omega}(\mathbf C_s(u))
+\lambda\,u/U_{\max},
\qquad \lambda=0.25,
\]

并在并列最优时选择较小目标。\(u=0\) 表示不施加新增的模型局部恢复目标，不表示历史运行中没有任何干预。年度 \(T_{\mathrm{turn,lb}}\) 取训练期实际周转时间的第 20 百分位；\(U_{\max}\) 取训练期正 headroom 的第 90 百分位并向下取整。表 S1 报告各年应用的参数。该局部目标模型不等同于完整航班网络恢复优化，也不直接模拟真实调度执行。

## S4. 评价量、稳定性边界与统计推断

### 筛查损失与恢复损失

在相同支持候选总体和预算下，令 \(\mathcal H^r_g\) 为参考后果排序的 Top-\(K\) 名单，\(\mathcal H^a_g\) 为替代排序名单，\(P^r_{i,g}\) 为参考优先级。筛查损失定义为

\[
L^{att}_g
=1-\frac{\sum_{i\in\mathcal H^a_g}P^r_{i,g}}
{\sum_{i\in\mathcal H^r_g}P^r_{i,g}},
\]

仅在参考总量为正时计算。参考 Top-\(K\) 在同一候选总体和预算下最大化参考总量，所以其替代损失非负。该量表示参考后果体系中的相对损失，不是已发生的航司成本。

令 \(u^r_{i,g}\) 为 HJ 参考表示下的目标，\(u^a_{i,g}\) 为比较表示下的目标；两者均在同一个 HJ 参考目标函数 \(J^r\) 和同一支持情景下重新评价。定义

\[
\Delta^{rec}_{i,g}
=J^r_{i,g}(u^a_{i,g})-J^r_{i,g}(u^r_{i,g}),\qquad
V^r_{i,g}=J^r_{i,g}(0)-J^r_{i,g}(u^r_{i,g}),
\]

以及队列恢复损失

\[
L^{rec}(\mathcal C)=
\frac{\sum_{(i,g)\in\mathcal C}\Delta^{rec}_{i,g}}
{\sum_{(i,g)\in\mathcal C}V^r_{i,g}}.
\]

只有分母为正时才报告该比率。\(L^{rec}\) 不必限制在 0 与 1 之间；分母为零时比率未定义，不能记为零。每种管理目标有其自己的 HJ 参考最优解与恢复价值分母。最优性仅指当前局部模型中的最优，不是经真实航空运行验证的最优恢复动作。

### 决策稳定性充分条件

Stage-I 设参考 Top-\(K\) 名单为 \(\mathcal H^r_g\)，名单内外最小分差为

\[
m_g=\min_{i\in\mathcal H^r_g,\;j\notin\mathcal H^r_g}(P^r_{i,g}-P^r_{j,g}).
\]

若替代分数可写为 \(P^a_{i,g}=P^r_{i,g}+\delta^I_{i,g}\)，定义名单内外差分扰动上界

\[
\Delta^I_g=
\max_{\substack{i\in\mathcal H^r_g\\j\notin\mathcal H^r_g}}
|\delta^I_{i,g}-\delta^I_{j,g}|.
\]

对任一入选—未入选对，有

\[
P^a_{i,g}-P^a_{j,g}\ge m_g-\Delta^I_g.
\]

因此，\(\Delta^I_g<m_g\) 足以保证 Top-\(K\) 名单不变。该比较要求分数在同一尺度上，不能把原始延误分钟和 CU 直接代入。

Stage-II 令 \(u^r=\arg\min_uJ^r(u)\)，参考最优目标与次优目标间隔为

\[
\gamma=\min_{u\ne u^r}\{J^r(u)-J^r(u^r)\}.
\]

若 \(J^a(u)=J^r(u)+\delta^{II}(u)\)，并定义
\[
\Delta^{II}=\max_{u\ne u^r}|\delta^{II}(u)-\delta^{II}(u^r)|,
\]
则
\[
J^a(u)-J^a(u^r)\ge\gamma-\Delta^{II}.
\]
因此，\(\Delta^{II}<\gamma\) 足以保证参考动作仍为最优，并遵循相同的并列规则。两个条件都是充分而非必要条件；未满足条件不表示决策必然变化。

### 依赖结构比较的边界

令 \(P_J\) 为联合情景分布，\(P_M\) 为保留原始加权边际的乘积耦合，且两者使用同一可行目标集合。设
\(e_{\boldsymbol\omega}(u)=J_{\boldsymbol\omega}(u;P_J)-J_{\boldsymbol\omega}(u;P_M)\)。
对任一比较目标 \(v\) 和 HJ 最优目标 \(u_J^*\)，

\[
\begin{aligned}
J_{\boldsymbol\omega}(v;P_M)-J_{\boldsymbol\omega}(u_J^*;P_M)
={}&[J_{\boldsymbol\omega}(v;P_J)-J_{\boldsymbol\omega}(u_J^*;P_J)]\\
&-[e_{\boldsymbol\omega}(v)-e_{\boldsymbol\omega}(u_J^*)].
\end{aligned}
\]

这表明依赖结构只有在改变不同目标之间的相对评价时才可能改变选定动作；对所有目标都相同的加性偏移不会改变排序。若固定目标下的后果准则对未决原始状态可分离、所有加权边际一致，且目标集合与 effort 项不随表示变化，则两种表示下各目标的期望准则相同。这是边际充分性的一个充分条件，不是必要条件。

### 重抽样与报告方式

不确定性区间以飞机链 episode 为重抽样单位；同一 episode 中 PRE/TURN 阶段及其可用滚动节点随 episode 一同进入重抽样。文中保留的 Stage-I 与 Stage-II 95% 区间为 2,000 次 episode-cluster percentile bootstrap 输出。Stage-I 的 Top-\(K\) 是集合决策，因此每次重抽样都重新形成候选集、容量、排序、并列处理和参考保留量；不能把已经选定的名单当作固定样本后仅重抽其成员。年度点估计分别报告，不把不同年份的候选案例合并成一个大样本。表中不带区间的目标一致率、\(A_0/A_5\)、目标均值与激活比例均为描述性点估计。

### S5.7 样本量稳定性检查的识别边界

独立的 M5-b 检查覆盖 \(N\in\{128,256,512,1024,2048,4096\}\)，并以 \(E=4096\) 作为评估参考。六个年度均未在该网格内识别出稳定性边界；在 \(N=4096\) 的状态为 **NOT_IDENTIFIABLE_AT_THIS_N**。因此，结果不表示 \(N=4096\) 已足够，也不识别达到稳定所需的最小样本量。正文结果应限定为本研究已评估队列与支持范围内的描述性证据。

本轮六年输出不提供全体 Stage-II 有效总体上的恢复机会覆盖率、覆盖率与筛查优先级的关联、包含部分支持状态的阈值×headroom 消融、同容量 temporal attribution，或同一航班链内完整滚动轨迹结果。本文不把这些未报告的量写成零值，也不据此扩展主文的经验结论。
