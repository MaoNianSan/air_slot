# FINAL_EXECUTION_RESOURCE_PLAN_V2（基于 R6 pilot + R7 校准实测）

取代 `RESOURCE_BUDGET_REAL_MEASURED_V1.md` 的 chunk=4 外推部分（其 12–19 h / 25–40 h 每年前推已被 R7 chunk=64 实测证伪并显著下修）。数据基础：E1 c64 4:47.75（2 块）、E2/E3 c64 6:57（2+2 块）、E4 N=128/N=256 各 ~30 min（四阶段，硬停止 OK）、块级固定成本 F≈62–67 s/item≈0、eval 与 N 近无关。

## 1. E1 full 六年度

- 单年：64 块 × ~65 s + bootstrap ≈ **1.0–1.5 h/年**。
- 六年度串行：**6–9 h**；3 并发（1 进程/年）≈ **2–3 h 墙钟**。
- 内存：≤3.6 GiB/任务。

## 2. E2/E3 full 六年度

- 单年：128 块（两遍）× ~65 s ≈ 2.1–2.4 h + bootstrap ≤1 min → **2.5–3 h/年**。
- 六年度串行：**15–18 h**；3 并发 ≈ **5–6 h 墙钟**。
- 内存：≤3.9 GiB/任务。可为唯一"重"链，建议独立波次。

## 3. E4 full 六年度（全网格 128…4096）

- 单年：headroom ~6 min + fit×6 档（近常数，合计 ~10–15 min）+ ladder ~1.6 min + eval×6 档（~21.5 min/档 ≈ 2:09）+ 汇总 ≈ **2.5–3.5 h/年**。
- 六年度串行：15–21 h；**6 worker 并发（每年一 worker）≈ 2.5–3.5 h 墙钟（单波次）**。
- 内存：单 worker 峰值实测 5.2–13.6 GiB（两轮采样）；6×13.6=81.6 GiB ≤ 102.3 GiB 预算 ✓（≥40 GiB 余量）。

## 4. 推荐并发（内存公式：并发 ≤ floor(102.3 / 单任务峰值)，≥20 GiB 余量）

1. **E4：6 worker 一年一 worker、单波次**（官方 e4_scheduler 原生内存感知）；
2. **E1/E2E3：每年 1 进程；批内 3 并发**；与 E4 波次错开（E2E3 单独波次）；
3. 全部单线程（OMP/MKL/OPENBLAS/NUMEXPR=1）；同年份/同输出目录禁止并发；断点续跑用各自检查点（E4 阶段级、E2E3 两遍、E1 chunk）；
4. 运行器纪律修订（来自 R7 事件）：time_v 按尝试序号命名；启动前检查 tag 现有 status/marker（单驱动）。

## 5. 预计云成本

- **机时**（单核任务小时）：E1 6–9 + E2/E3 15–18 + E4 15–21 = **36–48 机时**（并行不增加机时）。
- **墙钟**（推荐排程）：E4 波次 ~3 h（夜1）→ E2/E3 波次 ~5–6 h（夜2）→ E1 波次 ~2–3 h（夜2/3）≈ **总计 10–12 h 墙钟**（可两夜完成）。
- **费用公式**：费用 = 36–48 机时 × 实例时价（安装置类型 SA9.8XLARGE128 的实际账单价计算；按 ~¥8–15/机时区间粗算为 **¥300–700 量级**，正式数字以腾讯云账单为准——本计划不引用未核实的刊例价）。
- 另计：数据准备/审计/汇总 ~2–3 机时；总预算建议按 **40–55 机时** 申报。

## 6. 正式执行顺序（建议）

1. **启动前**：批准 `FULL_EXPERIMENT_EXECUTION_AUTHORIZATION_V1.json`；复核六年度输入门（登记 `SIX_YEAR_INPUTS_VALIDATED` 已就位）；启动 sampler。
2. **波次 A（夜1）**：E4 六年度 × 6 worker（`e4_scheduler`，每年独立目录/日志/阶段检查点）；完成后逐年校验 `E4_YEAR_STATE`（预期各自 `PILOT_COMPLETE_HARD_STOP` 或按协议终态）+ EVAL_MANIFEST。
3. **波次 B（夜2）**：E2/E3 六年度 × 3 并发（两波）→ 逐校两遍检查点。
4. **波次 C（夜2/3）**：E1 六年度 × 3 并发（两波）→ 逐校 chunk 组+摘要。
5. **收尾**：六年度汇总审计（只读）+ 资源报告 + 结果打包（**非论文表**，由后续分析授权决定）。
6. 全程：任何非零退出仅阻塞对应年份与其下游；重试用阶段级 resume，禁止盲目重启/重复启动同名任务。
